## 🌐 Español

### 📌 Descripción General
Este repositorio alberga un **sitio web multipágina y responsivo** desarrollado como parte de las prácticas del programa **Análisis y Desarrollo de Software (ADSO)** en SENA. 

El proyecto demuestra las competencias fundamentales del desarrollo *Frontend*: maquetación semántica con HTML5, diseño estilizado y adaptable mediante CSS3, navegación interactiva con JavaScript y despliegue continuo a través de **GitHub Pages**.

### 🛠️ Estructura del Proyecto
* `index.html`: Página principal con presentación de servicios, portafolio e interacción inicial.
* `generic.html`: Plantilla estándar interna para contenido estructurado y artículos.
* `elements.html`: Muestrario de componentes de UI (botones, tablas, formularios, tipografía y módulos).

### ⚙️ Funcionalidades Clave
1. **Diseño Adaptativo (Responsive Design)**: Interfaz que se ajusta a dispositivos móviles, tablets y monitores de escritorio.
2. **Estructura Semántica**: Código limpio organizado modularmente para facilitar el mantenimiento.
3. **Navegación Interactiva**: Menú lateral dinámico y componentes de UI estructurados.
4. **Despliegue Continuo (CD)**: Alojado y publicado globalmente en tiempo real mediante **GitHub Pages**.

## 🌐 English

### 📌 Project Overview
This repository contains a **responsive multi-page web application** developed as part of the **Software Analysis and Development (ADSO)** program at SENA. 

The project demonstrates core Frontend capabilities: clean HTML5 semantic markup, custom CSS3 styling, interactive JavaScript navigation elements, and automated deployment via **GitHub Pages**.

### 🛠️ Project Structure
* `index.html`: Main landing page showcasing services, portfolio sections, and main interactions.
* `generic.html`: Standard layout template for inner pages and articles.
* `elements.html`: UI component showcase (buttons, tables, forms, typography, and modules).

### ⚙️ Key Features
1. **Responsive Web Design**: Fully adaptable layout across mobile, tablet, and desktop viewports.
2. **Semantic Architecture**: Clean HTML5 structure combined with custom CSS styling.
3. **Interactive UI**: Dynamic sidebar navigation and styled media elements.
4. **Continuous Deployment**: Hosted and globally accessible using **GitHub Pages**.
