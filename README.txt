## 🌐 English Description

### 📝 Overview
This repository contains a **responsive web application** developed as part of the **Software Analysis and Development (ADSO)** technology program at SENA. The project demonstrates core capabilities in modern frontend development, UI/UX structure, semantic HTML5, custom CSS styling, and automated deployment via **GitHub Pages**.

### 🎯 Key Features
* **Responsive Web Design:** Fully adaptable layout across desktop, tablet, and mobile devices.
* **Semantic Structure:** Clean HTML5 architecture (`index.html`, `generic.html`, `elements.html`).
* **Interactive UI:** Dynamic sidebar navigation and styled media elements.
* **Continuous Deployment:** Deployed and hosted globally using **GitHub Pages**.

## 🌐 Descripción en Español

### 📝 Descripción General
Este repositorio alberga un **sitio web responsivo** desarrollado durante el programa tecnólogo en **Análisis y Desarrollo de Software (ADSO)** en el SENA. El proyecto pone en práctica fundamentos clave de desarrollo frontend, diseño UI/UX, maquetación semántica con HTML5, estilos CSS3 y despliegue continuo a través de **GitHub Pages**.

### 🎯 Funcionalidades Clave
* **Diseño Multidispositivo:** Interfaz adaptable a diferentes resoluciones (móvil, tablet y escritorio).
* **Estructura Semántica:** Código limpio organizado en componentes (`index.html`, `generic.html`, `elements.html`).
* **Navegación Interactiva:** Menú lateral dinámico y componentes de UI estructurados.
* **Despliegue en la Nube:** Publicado y accesible en tiempo real mediante **GitHub Pages**.
